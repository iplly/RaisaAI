# ПРАВИЛА

## ⛔ АБСОЛЮТНЫЙ ЗАПРЕТ НА ИЗМЕНЕНИЕ C++ КОДА

- **НИКОГДА, НИ ПРИ КАКИХ ОБСТОЯТЕЛЬСТВАХ** агенту не разрешается **изменять** C++ код.
- Запрещено **любое** вмешательство в файлы с расширениями `.cpp`, `.h`, `.hpp`, `.cc`, `.cxx` и любые другие файлы с исходным кодом C++: **создание, редактирование, удаление, переименование, перемещение**.
- Запрещено **самостоятельно** вносить любые правки в C++ код, даже если они кажутся тривиальными или необходимыми.
- Запрещено **выполнять** команды и скрипты, которые изменяют C++ файлы (например, `sed`, `patch`, автоматические исправления и т.п.).
- Запрет действует **для этого проекта и для всех остальных проектов**.

## 💬 РАЗРЕШЁННЫЕ ДЕЙСТВИЯ С C++ КОДОМ (ТОЛЬКО КОНСУЛЬТАЦИИ)

Агент **может**:

- **Смотреть** и анализировать C++ код.
- **Объяснять**, как работает тот или иной фрагмент.
- **Предлагать** исправления, улучшения, оптимизации.
- **Подсказывать**, как реализовать ту или иную функциональность.
- **Помогать** со сборкой проекта, настройкой, диагностикой (без изменения файлов).
- **Отвечать** на вопросы, связанные с C++.

⚠️ **ВАЖНО**: Все эти действия не должны приводить к **изменению** C++ файлов. Предложения и советы допустимы, но их **реализация** остаётся за пользователем или другим исполнителем.

## ✅ РАЗРЕШЁННАЯ ОБЛАСТЬ РАБОТЫ

- Агенту разрешено **изменять** только код Python (`.py`) и JavaScript (`.js`).
- Любые другие файлы и языки — вне компетенции агента.

## 🚦 ПРАВИЛО ОДНОГО ШАГА (ОБЯЗАТЕЛЬНО)

- **НЕ** браться за несколько задач сразу.
- Делать **только ОДНУ** задачу/шаг за раз.
- Начинать следующую задачу **только после явного разрешения пользователя**.
- Не проявлять самодеятельность: не расширять рамки текущего шага, не «заодно» исправлять соседние проблемы.
- Если задача не однозначна — сначала **уточнить у пользователя**, а не действовать.

## ⚠️ ОТВЕТСТВЕННОСТЬ

- Данные правила не подлежат обсуждению, не допускают исключений и расширительного толкования.
- Нарушение запрета на изменение C++ кода недопустимо.
